# Invage v0.3.6

Released 2026-10-10 from `main`. Utarus remains pinned to `v4.2.3`.

## Changes

- Agents can discover nine stored-data datasets with `get_data_dictionary` and construct read-only `query_data` filters, selections, sorting, grouping and count/sum/min/max aggregates. All domain roles receive both tools and usage guidance. Queries enforce authenticated user scope, exact decimal sums, native currency/unit partitions, explicit unknowns, revision-pinned pagination and response limits. See [query documentation](../data-query.md).
- `get_portfolio` and `list_option_trades` expose retained execution dates, reconciled opening ranges, broker coverage and sync caveats. Current position, expiry, capture and sync dates are distinguished from execution dates.
- Fix quote provenance/precision, OCC contract matching, per-lot option multipliers, missing OI, long-call payoff labels, currency-safe portfolio/household analysis, source visibility in broker tools, multi-account IBKR NAV parsing/pagination, property medians and URA lot categories. HTML report filenames stay inside the authenticated user folder. See [accuracy audit](../audits/2026-10-10-agent-tool-data-accuracy.md).
