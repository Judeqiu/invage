# Invage v0.3.15

Released 2026-10-12 from `main`. Utarus remains pinned to `v4.2.8`.

## Changes

- Dashboard section 03 adds a Timeline alternative beside Open, History and Rolls. Contract rows show observed holding periods, recorded opening and closing events, expiry dates and roll arrows with their original evidence level.
- Contract search and call/put filters, keyboard-accessible evidence details and horizontal scrolling work on desktop and mobile. Account histories remain separate. Partial history failures retain available records and offer a refresh.
- Past-date views exclude subsequent activity. Missing opening dates are not invented; position disappearance does not establish a close, and possible roll relationships remain dashed.
- Management → Agent Configuration → Portfolio dashboard controls the default option view. The code default preserves the Open table; this deployment selects Timeline for VeloVest.
