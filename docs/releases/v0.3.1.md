### Extra steps for this version

- **Pin-only upgrade.** No agent code required.
- Channel format spine is **off by default**. Do **not** set `UTARUS_CHANNEL_FORMAT_ENABLED=true` until you intend to soak (see Env).
- Optional later soak: enable with `UTARUS_CHANNEL_FORMAT_GATE_MODE=observe` first, then tighten.

## Breaking changes

None when channel-format flags unset (default). With spine on: bad markdown may fail delivery / re-prompt / observe-log depending on `GATE_MODE`.

## Data / migration

None required. Optional assistant `content_ir` on chat messages only if `UTARUS_CHANNEL_FORMAT_STORE_IR=true` (default false).

## Env / secrets

No new required secrets. Unchanged: `TELEGRAM_BOT_TOKEN`, optional `TELEGRAM_BOT_USERNAME`.

Optional (defaults keep legacy path):

| Variable | Notes |
|----------|--------|
| `UTARUS_CHANNEL_FORMAT_ENABLED` | Master switch; **default off** |
| `UTARUS_CHANNEL_FORMAT_GATE_MODE` | `observe` \| `fail_delivery` \| `reprompt_once` |
| `UTARUS_CHANNEL_FORMAT_STORE_IR` | default false |
| Per-channel overrides | `WEB` / `TELEGRAM` / `SLACK` / `HTML_REPORT` (inherit master) |

## What changed (product)

- Utarus **v3.0.0-beta.14**: channel format IR + quality gate + multi-channel renderers (Telegram HTML, Slack mrkdwn, HTML report). Inactive until flags enabled.
- Invage product code unchanged from v0.3.0 (help-first + Telegram link/push).
