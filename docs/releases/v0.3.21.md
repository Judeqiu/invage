# Invage v0.3.21

Released 2026-10-13 from `main`. Utarus remains pinned to `v4.2.8`.

## Changes

Option timeline rows keep related contracts together in roll order, rather than separating closing and replacement legs by expiry. Roll arrows use straight lines; same-day rolls appear as vertical arrows between adjacent lanes. Branching relationships remain together, with closing legs before replacements where possible; reused-contract cycles retain deterministic ordering. Account separation, dated evidence and dashed possible/review links are preserved.

Preserve runtime dependencies and configuration. No SQL migration, dependency installation or framework upgrade is required.
