# Invage v0.3.4

Released 2026-10-10 from `main`. Utarus remains pinned to `v4.0.2`.

## Changes

- Dashboard Section 01 includes a Discuss button for every displayed option contract. It starts a focused chat with the exact contract, broker, quantity, multiplier and selected snapshot date. The action stays in the sticky contract cell, supports keyboard activation, prevents duplicate clicks during loading and displays launch errors inline.
- Historical discussions preserve the archived broker position date and ask the agent to verify current holdings and quotes.
- MooMoo, Tiger and Webull opening fills restore option opening history and credits. Gross proceeds are labeled before fees when net credits cannot be established.
