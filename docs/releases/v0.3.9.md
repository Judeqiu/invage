# Invage v0.3.9

Released 2026-10-10 from `main`. Utarus remains pinned to `v4.2.3`.

## Changes

The live v0.3.8 query check found that complete financial state exceeded the
50,000-record expansion limit. Even a portfolio-only root filter expanded all
historical observations before filtering, making unrelated large history block
small requests.

Financial `root` equality filters now scope the source before expansion. An
explicit `source:{path:JSON_POINTER}` can select any authorized financial
subtree, such as `/portfolio` or `/option_observations/0`, while retaining the
original paths, types, missing-data semantics and investor revision. Source
counts identify the selected subtree. Private auth and broker access fields
remain inaccessible. Disjunctions are not incorrectly narrowed to one root.

All v0.3.8 financial, accounting, valuation and archive datasets remain
available. Oversized queries still fail explicitly; narrow the source rather
than dropping history or returning incomplete totals.
