# Velovest v0.3.24

Source release dated 2026-11-27 from `main`. Utarus is pinned to
`github:Judeqiu/utarus#v4.2.57` at
`ad22ffabec312913ecc6fc744ce473c994a99d6a`.

## Changes since v0.3.23

- Options decision reports include urgent short calls alongside short puts.
  Reports summarize position decisions, identify quote sources and freshness,
  and use timestamped Futu market snapshots and order books when available.
  They show credit roll examples when quotes support them and retain the full
  candidate evidence in a private Notes attachment.
- Utarus adds long-chat context compaction with the original transcript
  preserved and configurable admin Piggyback sign-in.
- The Velovest founder note appears on the About Us page.

[Full source comparison](https://github.com/Judeqiu/invage/compare/v0.3.23...v0.3.24).

## Deployment

Deploy the tagged source to [Velovest chat](https://chat.velovest.lextok.com)
through Agent Ops `fast-deploy.sh` for `victorconsultant`. Prepare the clean
tagged source and runtime dependencies while `victorconsultant` and
`victorconsultant-drive` are serving traffic. For upgrades from before
Utarus v4.2.55, stage the locked runtime dependencies, including `qrcode`,
and review the [management upgrade notes](https://github.com/Judeqiu/invage/blob/v0.3.24/docs/ops/velovest-manager.md).

Utarus v4.2.57 requires PostgreSQL migrations 37 through 40 for Piggyback
sessions, credentials, and settings. Confirm the installed schema and take
a recovery point. With both writers stopped and the prepared package active,
run `node node_modules/utarus/dist/database/cli.js migrate` using the existing
Velovest database environment. Start both replacements immediately after
migration. Check `node node_modules/utarus/dist/database/cli.js check personal`,
both units, the installed framework version, and direct sign-in. Review the
Piggyback setting and smoke procedure in the [Utarus v4.2.57 upgrade notes](https://github.com/Judeqiu/utarus/blob/v4.2.57/docs/releases/v4.2.57.md).

The [homepage deployment](https://github.com/Judeqiu/invage/blob/v0.3.24/website/deploy/README.md)
is separate from the chat deployment.

## Validation

The app and website builds passed, along with 46 focused app tests and 5
website tests. Chromium exercised chat report generation, private Notes,
and the independent opt-in schedule using model and broker fixtures.

The packaged migration CLI upgraded an isolated Utarus v4.2.55 personal database
from schema 36 to 40. Readiness passed, a repeated migration succeeded, and the
existing registered-admin session and saved user state remained readable.

## Rollback

PostgreSQL recovery point. Reconcile writes made after that recovery point.
