# Invage v0.3.2

Released 2026-10-09 from `main`. Utarus remains pinned to `v4.0.2`.

## Portfolio currency fix

Accounts without a saved reporting currency now calculate portfolio NAV in USD.
Settings → Portfolio presets USD and returns the same effective currency used by
the dashboard. A saved user selection takes precedence over the default.

Mixed-currency holdings, cash and deposits use live FX. Dashboard reports and new
snapshots use the same default. Missing FX still makes NAV unavailable rather
than assuming currencies are interchangeable. Existing account state and archived
snapshots are not rewritten.
