# Invage v0.3.7

Released 2026-10-10 from `main`. Utarus remains pinned to `v4.2.3`.

## Changes

- Routine holdings, trade dates, balances, quotes, filtering and tool-computed totals use host read tools with zero expert consultations. Experts are reserved for requested analysis, recommendations, writes, syncs and unresolved reconciliation. Factchecker handles disputed evidence, explicit audits and material analytical claims.
- Removed mandatory delegation and always-last audit instructions from the host purpose, message context and routine scheduled-task guidance for both product profiles. Host ledger-write and strategy-tool boundaries remain intact. See [routing policy](../direct-routing.md).
- Added direct `get_portfolio`, `list_option_trades`, `get_quote` and `get_option_quotes` access. Batch option quotes share one chain fetch per underlying/expiry within a call, preserve per-contract failures, and distinguish per-share prices, fetch time and unknown option quote timestamps.
- Injected a trusted server clock for relative date windows. Lookups must preserve requested filters, paginate complete results and avoid guessing a single contract or adding unsolicited risk analysis.
