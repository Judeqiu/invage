# Invage v0.3.5

Released 2026-10-10 from `main`. Utarus is pinned to `v4.2.3`.

## Changes

- Discuss opens chat in a floating right sidebar on desktop and full screen on mobile. The dashboard stays available when the panel closes.
- Each discussion keeps the exact option contract, broker and snapshot context. Reopening a discussion preserves its conversation and draft without sending the opening prompt again.
- Chat launch errors support retry; keyboard focus returns to the selected Discuss button when the panel closes. Full chat remains available from the panel.
- Utarus provides the reusable same-origin domain chat panel bridge documented in its WebUI integration guide.
