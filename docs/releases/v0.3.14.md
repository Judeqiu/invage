# Invage v0.3.14

Released 2026-10-12 from `main`. Utarus remains pinned to `v4.2.8`.

## Changes

- Option lifecycle events use canonical field order, preventing false conflicts when PostgreSQL jsonb reorders a previously imported event. Genuine conflicts report the differing field names.
- Reusing an observation sync ID with changed option evidence fails before ledger writes. Retry timestamps and archive paths may change without creating a duplicate observation.
- Observation preparation runs on a copy before ledger reconciliation, so failed validation or ledger transactions leave observation history unchanged.
- Database regression tests verify unchanged holdings, cash, executions, lifecycle events and journals across repeated imports, reordered fields and different raw bytes. They also cover retries after a books commit followed by a state-save failure. Independent sync attempts retain separate audit observations.
- Includes the previously committed public financial research integration for options analysis, already deployed to VeloVest.
