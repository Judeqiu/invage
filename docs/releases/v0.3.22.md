# Velovest v0.3.22

Released 2026-10-23 from `main`. Utarus remains pinned to `v4.2.34`.

## Changes

Dashboard account selectors use text labels without broker logos. Broker-wide aggregate choices are removed; users can select an individual broker account or All accounts. Risk and open-options table filters now distinguish individual accounts, including accounts at the same broker. History and roll selectors also offer account-level choices. Saved broker-wide selections and URLs fall back to All accounts.

This tag includes the previously committed changes already deployed through `f2a9602`, including broker sync reliability, reconciled execution evidence, and option discussion research improvements. The deployment delta from that live baseline is the dashboard filter update and release metadata.
