Connect a brokerage account

Invage pulls a snapshot of positions and cash. It cannot place or cancel orders. Dashboard marks stay Yahoo. Secrets are stored on your user file and never shown again in full.

Section 01

How a connection works

  1. Open Brokers and choose a card (Interactive Brokers, Tiger Brokers, MooMoo, or Webull).
  2. Click Connect, enable the channel, and paste the credentials listed below.
  3. Save, then Sync. Only lots and cash tagged with that channel are replaced. Other brokers stay untouched.
  4. Turning a channel off stops future pulls. It does not delete holdings.

Section 03

If something fails

  • IBKR 1013 / IP mismatch. Leave “Valid for IP Address” blank unless this page showed a static egress IPv4 to paste. A rotating server IP with a whitelist set will fail.
  • IBKR 1012 / expired token. Flex tokens last at most one year. Generate a new token; query IDs stay the same.
  • Tiger TBHK. Hong Kong licenses need the extra token (~30 days). Paste a fresh one when Sync says it expired. Invage does not auto-refresh it.
  • MooMoo trading account. Save the AppKey and private key. Invage discovers authorized accounts automatically. If Moomoo returns several, choose one from the list using its account card ending, then Save and Sync.
  • MooMoo clock skew (-12006). Sync retries once against server time. If it still fails, check the device clock and try again.
  • Webull access token. Some licenses require in-app 2FA. In Settings → Brokers → Webull, save your API credentials and click Create token. Approve the request in the Webull app within five minutes, click Check token status until it says NORMAL, then Sync. Invage stores the token privately and does not poll the app.
  • Paper / sim accounts. Only ingest a paper account if that is the id you pasted. Live books should use a funded live account.
  • jude_futu lots. Connecting MooMoo does not move Futu-tagged lots or fixed deposits. Recon those sleeves separately if you want one channel.
  • Not imported. Futures, short stock, combo/multi-leg options, and option rows missing strike/expiry/multiplier stay in the Sync skip list. They are never invented as holdings. Listed single-leg options that fill the shared option shape are imported on every connector. Fill history (Trades tab) is IBKR Flex only today.
